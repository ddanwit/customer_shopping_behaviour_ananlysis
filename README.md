# Customer Shopping Behaviour Ananlysis
## Комплексный анализ покупательского поведения

Данный проект представляет собой сквозной анализ данных о покупках 3 900 клиентов в розничной сети. Цель работы — выявить ключевые драйверы продаж, сегментировать клиентскую базу и предложить стратегии для увеличения выручки и лояльности.

## Задачи проекта:

Очистка и подготовка данных (Python): обработка пропусков (37 пропусков в колонке рейтинга), приведение типов, переименование столбцов, создание новых признаков (возрастные группы, частота покупок).

Анализ и SQL-запросы (MySQL): формирование витрин данных и выполнение 10 бизнес-запросов — от сравнения выручки по полу до сегментации клиентов (новые, возвратные, лояльные) и выявления товаров с наибольшей долей дисконтных продаж.

Интерактивный дашборд (Power BI): визуализация трендов, распределений и ключевых метрик для стейкхолдеров.

Итоговый отчёт и презентация (Gamma): структурированные выводы и практические рекомендации для маркетинга и управления ассортиментом.

## Ключевые результаты:

Клиенты с экспресс-доставкой совершают покупки в среднем на 3.4% дороже (60.48 USD против 58.46 USD).

5 товаров имеют долю дисконтных продаж выше 47% (Hat, Sneakers, Coat, Sweater, Pants), что требует пересмотра ценовой политики.

Выделены 3 сегмента клиентов: Loyal (3 116 чел.), New (833), Returning (701) — для каждого предложены механики удержания.

Топ-3 продукта в каждой категории (например, в категории "Одежда" — Blouse, Pants, Shirt) помогут оптимизировать рекомендательные системы.
